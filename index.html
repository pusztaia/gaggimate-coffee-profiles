Új profil hozzáadása

Az index kódját nem kell másolni vagy bővíteni. Egy új mappa és egy katalógusbejegyzés elegendő. A katalógus JSON-alapú, interaktív grafikonokkal, és GitHub Pages-en, build lépés nélkül fut.

Hozd létre a profil mappáját
profiles/uj-kave/, a fájlelnevezési konvenció szerint.

Tedd bele a JSON, PNG, recipe és changelog fájlokat
A PNG neve automatikusan a JSON stem + -profile.png.

Adj hozzá egy objektumot a katalógushoz
A profiles/catalog.json profiles tömbjéhez.
