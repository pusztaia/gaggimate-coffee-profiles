# Espresso kóstolási és visszajelzési útmutató

Gyors referencia a shotok értékeléséhez és visszajelzés adásához dial-in közben.

---

## A savas vs keserű probléma

Az érzékszervi tudományban a "sav-keserű összetévesztés" dokumentált jelenség. Nehéz megkülönböztetni a savasságot a keserűségtől, mert hasonló kellemetlen érzeteket kelthetnek. Ez téves diagnózishoz vezet az espresso shotok dial-in-je során. Íme Lance Hedrick útmutatása arról, hogyan lehet megkülönböztetni őket:

| | **Savas** (alulextrahált) | **Keserű** (túlextrahált) |
|---|---|---|
| **Időzítés** | Azonnal jelentkezik, gyorsan elhalványul ("magas hangfekvésű") | Lassan kúszik be, tartósan megmarad ("mély hangfekvésű") |
| **Textúra** | Éles, összehúzó, nyálelválasztást indít | Szárító, fanyar, karcoló |
| **Gondolj erre** | Citrom harapása, éretlen gyümölcs | Túlázott tea, grapefruit héja |
| **A shot valószínűleg** | Túl gyors, túl durva, túl hideg volt | Túl lassú, túl finom, túl forró volt |

**Gyors tesztek:**
- Összefut a nyálad? → Valószínűleg savas
- Szárazon érzed a szád, és az érzés tartósan megmarad? → Valószínűleg keserű
- Sós vagy umami ízű? → Alulextrahálás (ez egy kulcsfontosságú jelző, amit sokan kihagynak!)

**Gyakori csapda:** Sokan "keserűnek" mondják, amikor valójában "kellemetlent" értenek alatta. Ha a shot gyors volt, és az íz erősen üt be, majd gyorsan elhalványul, az savas, még akkor is, ha ösztönösen keserűnek neveznéd.

**Miért számít jobban az időzítés, mint a nyelv területe:** A "nyelvtérkép" (savas az oldalakon, keserű hátul) egy 1901-es mítosz. Az ízlelőbimbók az egész nyelven eloszlanak. Arra koncentrálj, *mikor* és *mennyi ideig* tart az érzet, ne arra, hogy hol.

## Hogyan kóstold a shotodat

1. **Először keverd meg** — Az espresso szétválik a csészében; a keverés egyesíti a rétegeket
2. **Szürcsöld** — A levegőztetés szétteríti az ízlelőfelületeden
3. **Hagyd a nyelveden időzni** — Figyeld meg, hol ütnek be az ízek
4. **Lélegezz ki az orrodon át** — Ez feltárja a komplexebb ízeket
5. **Figyeld a lecsengést** — Mi marad meg nyelés után?

**Kóstolj különböző hőmérsékleteken:** Az espresso íze hűlés közben változik. Egy forrón jónak tűnő, de hidegen kellemetlen shot rejtett extrakciós problémákat jelezhet.

---

## A négy értékelendő szempont

### 1. Balansz
Savas, keserű vagy balanszos a shot?
- **Savas** → több extrakció szükséges
- **Keserű** → kevesebb extrakció szükséges
- **Balanszos** → édesség jelen van, sem a savasság, sem a keserűség nem dominál

### 2. Test
Hogyan érződik a szádban?
- **Vékony/vizes** → valószínűleg alulextrahált
- **Szirupos/bevonó** → jó extrakció
- **Nehéz, de üres** → esetleg túlextrahált

### 3. Édesség
Érzel édességet?
- **Nincs** → alulextrahált (a cukrok nem oldódtak fel)
- **Jelen van** → jó extrakció jele

### 4. Lecsengés
Mi történik nyelés után?
- **Rövid/hirtelen** → alulextrahált
- **Kellemesen tartós** → jól extrahált
- **Száraz/fanyar** → túlextrahált

## Gyors visszajelzés sablon

Shot jegyzetek rögzítésekor vagy dial-in segítségkéréskor rögzítsd ezeket a lényegi adatokat:

```
Értékelés: _/5
Balansz: savas / balanszos / keserű
Test: vékony / jó / nehéz
Édesség: nincs / némi / jó
Lecsengés: rövid / tiszta / száraz
Egy dolog, amin javítani kell: _______________
```

**Példa:**
```
Értékelés: 3/5
Balansz: enyhén savas
Test: jó
Édesség: némi
Lecsengés: tiszta, de rövid
Egy dolog, amin javítani kell: több édesség, kevesebb savasság
```

## Mit árul el az ízed

| Amit érzel... | Valószínű ok | Próbáld... |
|---|---|---|
| Savas + vékony | Alulextrahálás | Finomabb őrlés, magasabb hőmérséklet |
| Savas + gyors shot | Túl durva őrlés | Finomabb őrlés |
| Sós vagy umami | Súlyos alulextrahálás | Hozam növelése 5 g-mal, vagy finomabb őrlés |
| Keserű + lassú shot | Túlextrahálás | Durvább őrlés |
| Keserű + száraz lecsengés | Súlyos túlextrahálás | Hozam csökkentése 5 g-mal, alacsonyabb hőmérséklet, rövidebb arány |
| Lapos/élettelen | Nem friss kávé vagy rossz hőmérséklet | Frissesség ellenőrzése, hőmérséklet állítása |
| Jó, de hiányzik a test | Túl hosszú arány vagy channeling | Rövidebb arány, jobb puck prep |
| Durva/hamuszerű | Túlextrahált vagy sötét pörkölés problémája | Durvább őrlés, alacsonyabb hőmérséklet, nyomáscsökkenés |

## Gyakori ízjegyek

Használd ezeket, ha pontosabban szeretnéd leírni az ízt:

**Pozitív:**
- Gyümölcsös (bogyós, citrusos, csonthéjas gyümölcs)
- Édes (karamell, méz, csokoládé)
- Diós (mandula, mogyoró)
- Virágos (jázmin, rózsa)

**Negatív (hibák):**
- Savas, savanyú, éles (alulextrahált)
- Keserű, égett, hamuszerű (túlextrahált)
- Száraz, fanyar (túlextrahált)
- Lapos, élettelen (nem friss vagy rossz hőmérséklet)
- Vizes, vékony (alulextrahált)

## Megjegyzések a különböző shot stílusokhoz

A balansz elvárások stílusonként eltérnek:

| Stílus | Elvárt jelleg | A "rossz" az lenne, ha... |
|---|---|---|
| **Hagyományos** (9 bar, 25-35 s) | Teljes test, balanszos, szirupos | Vékony, vizes vagy durva |
| **Turbo** (6 bar, 10-20 s) | Édesebb, kevesebb test, tisztaság | Zavaros vagy keserű |
| **Allongé** (hosszabb arány) | Könnyedebb test, élénk | Vizes komplexitás nélkül |
| **SOUP** (<2 bar) | Teaszerű, lédús, tiszta | Vékony íz nélkül |

Ne ítélj el egy turbo shotot a test hiánya miatt — ez elvárt. Tisztaság és édesség alapján ítéld meg.
